# Android interaction audit (rounds 3 and 4)

This audit compares every screen and flow of the Android app against Apple Music, Spotify and
YouTube Music conventions.

**Method**
* Device: isolated headless emulator `Medium_Phone` (Android 16, `-no-window -no-audio
  -read-only`, port 5562). The user's emulator and phone were never used.
* PC side: `protocol/tools/peer_client.py`. It paired with the phone, then ran as a PC media source
  (`--demo`), with `--no-reply` to simulate a PC that does not answer.
* Inputs: `adb input` taps and swipes. UI state was read via `uiautomator dump` and screenshots.
* Logic changes are covered by JVM unit tests: `InteractionTest`, `NavStateTest`,
  `TargetResolverTest`, `TranslationMergeTest`.

Screenshots: `docs/screenshots/android/` (`*_09_lyrics_translation`, `*_10_source_sheet`,
`*_11_permissions`, `*_12_pairing`, `*_13_about` for light/dark × zh/en, plus `r3_*`, `launcher_drawer`,
`splash`).

# Round 4: crash on track change, lyrics timing, spacing, navigation

**Method**
* Device: a new isolated headless AVD `MD_Agent_A17` (Android 17 / API 37 image, `-no-window
  -no-audio`, port 5562). Nothing else was touched; the emulator was stopped at the end.
* PC side: `protocol/tools/peer_client.py` (pairing) plus a scratch driver built on it that acts as
  the Windows host: a PC media source carrying `outputLatencyMs`, `lyrics.push` with translation for
  the phone or PC track, and `media.command next / previous` like the user's PC log. Phone media:
  the `testplayer` fixture.
* Test lyrics: word-timed lines (with inner spaces, CJK and an emoji surrogate pair), line-timed
  lines (one wraps to three rows), translations, an intro gap and an 8 s interlude.
* Inputs: `adb input`, `uiautomator dump`, `screencap`, `screenrecord` + ffmpeg contact sheets for
  the transitions. JVM unit tests for all extracted logic (112 tests, 0 failures).

Screenshots: `docs/screenshots/android/` - all `{light,dark}_{en,zh-CN}_*` replaced (new navigation,
spacing and lyrics), plus `r4_nav_home`, `r4_nav_lyrics`, `r4_nav_settings_mini_player`,
`r4_lyrics_offset`, `r4_lyrics_interlude`, `r4_lyrics_browsing_pill`, `r4_settings_lyrics_timing`,
`r4_diagnostics_crash_report`, `r4_font130_{player,lyrics}`, `r4_small360_{player,lyrics}`,
`r4_landscape_{player,lyrics}`.
