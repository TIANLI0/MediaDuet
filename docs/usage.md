# MediaDuet 使用指南

[返回首页](../README.md) · [首次安装与配对](../README.md#快速开始) · [English](../README.en.md)

## 先分清三种功能

| 功能 | 实际发生什么 | 声音从哪里播放 |
| --- | --- | --- |
| 远程控制 | 在电脑上暂停、切换手机歌曲，或反过来操作 | 原设备当前的耳机或扬声器 |
| 接力播放 | 在另一台设备的播放器里查找并打开当前歌曲，尝试接上进度 | 目标设备的音频输出 |
| 音频传输 | 把一台设备播放的声音传到另一台设备 | 接收设备的音频输出 |

日常跨设备切歌只需要远程控制，无需开启音频传输。

## 通过蓝牙连接

电脑和手机可以通过同一局域网或蓝牙连接。使用蓝牙前：

1. 在 **Windows 系统设置 → 蓝牙和设备**中，完成电脑和手机的系统蓝牙配对。
2. 在手机 MediaDuet 中打开 **设置 → 连接 → 配对模式**。
3. 在电脑 MediaDuet 中打开 **设置 → 设备与配对 → 配对新手机**，选择手机，核对 6 位配对码并在两端确认。

系统蓝牙配对和 MediaDuet 配对是两个步骤，都需要完成。自动连接模式支持在局域网和蓝牙之间切换。蓝牙实机支持情况见[兼容性列表](compatibility.md)；连接机制见[蓝牙与局域网文档](bluetooth.md)。

## 自动暂停与恢复

在电脑端 **设置 → 播放仲裁**中设置。“播放仲裁”决定两台设备同时播放时，哪一端继续。

| 模式 | 行为 |
| --- | --- |
| 电脑优先（默认） | 电脑播放声音时暂停手机音乐，电脑安静后按设置恢复 |
| 手机优先 | 手机播放时，暂停电脑上可控制的媒体 |
| 后播放者优先 | 最近开始播放的一端继续，另一端暂停 |
| 自定义优先级 | 按设置的应用优先级决定 |
| 关闭 | 两台设备各自播放，不自动干预 |

可以关闭自动恢复、调整恢复前的等待时间，或设置成仅在使用指定耳机等音频输出设备时介入。

**自动恢复只针对 MediaDuet 自动暂停的内容。** 你手动暂停的音乐会保持暂停。游戏声音可以触发暂停手机音乐，但游戏本身通常不能被远程暂停。

## 歌词与本机模式

两端都可以显示同步歌词、逐字高亮和译文，也可以手动调整歌词时间。Windows 还提供桌面悬浮歌词、任务栏歌词和迷你播放器。

Android 可在 **设置 → 歌词**中开启“歌词通知”，在通知栏和锁屏上显示当前歌词。Android 16+ 会请求以实时通知显示，ColorOS 16 可显示为流体云；实际展示取决于系统、通知权限和相关系统设置。

只想在本机使用时，选择 **“仅此电脑”或“仅此手机”**，即可控制本机播放、查看歌词，无需配对。Windows 的桌面歌词和任务栏歌词也可在本机模式下使用。

## 在另一台设备上继续听

- 电脑端：点击播放卡片中的 **“在手机上继续 / 在电脑上继续”**。手机播放时，也可使用电脑任务栏上的“在电脑上继续”按钮。
- 手机端：打开 **“播放来源”**面板，选择接力到另一端和目标播放器。

目标设备需要安装对应播放器，并拥有这首歌的播放权限。MediaDuet 会查找歌曲、尝试从当前进度播放，成功后暂停原设备。

项目包含网易云音乐、QQ 音乐和 Spotify 的接力适配，但适配不代表所有版本和设备都已验证。部分播放器或跨曲库匹配只能打开歌曲或搜索结果，需要手动开始播放；Spotify 等目标仍待真机验证。手机 App 在后台时，可能需要点击通知才能继续。各目标的具体状态见[兼容性列表](compatibility.md#handoff-targets-continue-on-the-other-device-protocol-87)。

## 把声音传到另一台设备

| 方向 | 使用方式 | 当前限制 |
| --- | --- | --- |
| 手机 → 电脑 | 完成系统蓝牙配对，开启“接收手机音频”；必要时在手机上选择电脑作为声音输出 | 已实现，仍需真机验证兼容性 |
| 电脑 → 手机 | 使用局域网音频传输 | 实验功能，有明显延迟，不适合边看视频边听 |
| 手机 → 电脑（局域网） | 暂不支持 | 请使用蓝牙方式 |

接收手机蓝牙音频时，自动播放仲裁会暂停介入，也会禁用电脑到手机的音频传输，以避免循环。更多机制与限制见[音频说明](audio-routing.md)。

## 连接与播放问题

| 问题 | 先检查什么 |
| --- | --- |
| 电脑发现不了手机 | 确认连接同一局域网、手机端配对模式仍有效，并检查所需连接权限；尝试手动输入手机 App 显示的 IP 和端口（默认 `47321`） |
| 系统不允许开启通知使用权 | 在系统“应用信息 → 右上角菜单 → 允许受限设置”中放行，再返回授权；具体名称因手机而异 |
| 连接成功，但看不到手机歌曲 | 先让手机播放器开始播放，再到“设置 → 权限与后台”确认通知使用权已开启 |
| 锁屏后容易断开 | 解除电池优化限制，按“权限与后台”页面的厂商指引允许后台活动 |
| 某个按钮不可用，或无法拖动进度 | 播放器可能未开放对应控制能力；换一个支持系统媒体控制的播放器验证 |
| 关闭电脑窗口后还在运行 | 这是正常行为：MediaDuet 留在系统托盘继续同步；完全退出请使用托盘菜单 |

MediaDuet 主要通过播放器提供的系统媒体控制接口工作，能否获取进度、暂停或切歌取决于播放器。已验证的播放器和系统范围见[兼容性列表](compatibility.md)，具体验证过程见[测试记录](testing.md)。

Windows 还支持键盘媒体键控制手机播放、电脑应用单独调音量；两端都可在软件内检查和安装更新。

## 隐私与联网

MediaDuet 无需注册账号。设备间的控制和同步通过局域网或蓝牙直接进行，通信加密，不经过云端转发。

手机端的通知使用权用于访问系统媒体会话。MediaDuet 不读取、保存或发送通知正文，也不上传联系人或聊天内容。

以下功能需要访问互联网：

| 功能 | 外部服务与使用的信息 |
| --- | --- |
| 在线歌词、高清封面 | 从网易云音乐、QQ 音乐、LRCLIB、iTunes 等服务查询；按查询需要使用歌名、歌手、专辑、时长等歌曲信息 |
| 跨曲库接力查歌 | 向目标曲库查询歌曲信息 |
| 检查与下载更新 | 访问 GitHub |

可以在设置中关闭在线歌词源、高清封面查询和自动更新检查，并自行决定是否使用接力播放。原播放器的登录、会员和歌曲访问要求仍然适用。
